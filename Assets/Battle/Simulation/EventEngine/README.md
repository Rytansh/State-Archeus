# Documentation

This folder handles all assets related to event resolution and VM operations, classified as the event engine, with several subfolders:

Behaviours - Handles all behavioural models, and processing. This includes trigger collection, behavioural condition checking and behaviour execution models.

Events - Manages all events, including the event model, processing and associated metadata.

VM - Includes the ability interpreter, and classifies the model and metadata associated with all programs and instructions.
