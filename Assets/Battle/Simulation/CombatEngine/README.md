# Documentation

Includes all the assets related to gameplay logic, classified as the combat engine. This has several subfolders:

Actions - Describes the model for actions, and gameplay associated with action point economy.

Cards - Handles everything associated with combat cards, including positioning, identity and rules.

GameplayMechanics - Describes the pipelines and rules associated with certain gameplay logical mechanics, such as damage, healing, death effects, and combat effects.

Participants - Describes all entities that are associated with the battle, such as players, in-game entities and rulings concerning those entities.

Stats - Contains all stat information, such as modifier structure, application rules and stat types.

Turnflow - Manages all turn flow logic, including all phases related to turns, and additional mechanics related to turns.
