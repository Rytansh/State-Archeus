# Documentation

This folder contains all scripts and assets related to battle. Each subfolder describes their respective area:

Contracts - All interfaces, contracts and assumed definitions reside here and should be adhered to within the codebase.

Inputs - Manages all input processing and routing related to battle only.

Presentation - Manages all battle presentation related structure, including assets, the command and state pipeline, timeline management, and visual control.

Scheduling - Defines a top layer for scheduling all battle related systems.

Simulation - Handles all battle related simulated work, such as entity management and modification, event and VM processing behaviour and game mechanic pipelines and logic.
